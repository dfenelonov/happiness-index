# Индекс счастья — MVP

Короткий тест: личный индекс счастья, тип личности и три «утечки счастья». Полный LLM-отчёт — платный.
MVP проверяет дохождение, шеринг и конверсию в покупку (пороги — `docs/SPEC.md`, раздел 1).

## Как начать с Claude Code

1. Открой эту папку в терминале и запусти `claude`.
2. Первое сообщение:

   > Прочитай CLAUDE.md и docs/. Выполни этап 0 из docs/PLAN.md. Перед стартом задай вопросы, если что-то в ТЗ неясно.

3. После каждого этапа проверь результат и дай добро на следующий.

## Что заполнить самому

- `.env` по образцу `.env.example` (ключи ЮKassa — тестовые)
- Тексты шкал вместо `TODO_LICENSED_TEXT` в `config/questionnaire.yaml` — после проверки лицензий
- Контакты служб помощи и юридические тексты вместо `TODO_LEGAL`

## Структура документов

| Файл | Что внутри |
|---|---|
| `CLAUDE.md` | Правила для Claude Code |
| `docs/SPEC.md` | ТЗ: экраны, подсчёт, данные, API, приёмка |
| `docs/PLAN.md` | Этапы работ |
| `docs/ANALYTICS.md` | События и дашборд |
| `docs/LLM_REPORT.md` | Генерация отчёта |

| `config/app.yaml` | Контент: индекс страны, цены, контакты |
