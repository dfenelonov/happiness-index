# Готовность к запуску MVP: go / no-go

Состояние на 21.11.2026, ветка `nextjs-mvp`, после пяти доработок (защита прода, повторная покупка, фоновая
генерация, алерты и бэкапы, поддержка).

Статусы:
- **готово** — сделано и проверено тестами или smoke;
- **мок** — работает на заглушке, нужен настоящий сервис;
- **не сделано** — нужна работа агента;
- **нужен я** — действие владельца.

Кто делает: **агент** или **я** (владелец). Блокер — нельзя пускать реальных людей, пока пункт не закрыт.

Проверочные инструменты:
- `npm test` — 144 юнит-теста;
- `npm run smoke` — 56 HTTP-проверок всего пути;
- CI (`.github/workflows/ci.yml`): e2e, скриншоты, Docker, бэкап и восстановление в контейнере;
- `/dev/qa` и [MANUAL_QA.md](MANUAL_QA.md) — ручная проверка.

## Вердикт

**Сейчас — no-go, но со стороны кода блокеров больше нет, кроме первого прогона CI.** Всё остальное, что
блокирует запуск, — твои действия: юрлицо и договоры, тексты, ключи и сервер.

Порядок:

1. **Push ветки → CI зелёный** (агент чинит, если упадёт): e2e, скриншоты, Docker, бэкап в контейнере.
2. **Ты, параллельно:**
   1. статус и договор с ЮKassa → выбор `RECEIPT_MODE`;
   2. уведомление РКН;
   3. юр. тексты с юристом;
   4. `SUPPORT_EMAIL`;
   5. вычитка [TEXTS_REVIEW.md](TEXTS_REVIEW.md) и данных ВЦИОМ.
3. **Сервер:**
   1. VPS, домен, HTTPS;
   2. `.env` по LAUNCH.md: тестовые ключи ЮKassa, SMTP, Telegram-бот, бакет для бэкапов, сильный
      `ADMIN_PASSWORD`; приложение само не стартует, если чего-то критичного не хватает;
   3. проверочный алерт и проверочное восстановление бэкапа.
4. **Тестовый платёж end-to-end:** успех, отказ, закрытая вкладка (письмо пришло), повторный заход
   («Открыть мой разбор»), «Восстановить доступ». Затем 3–5 реальных отчётов YandexGPT.
5. **Ручная проверка** по [MANUAL_QA.md](MANUAL_QA.md) на проде с тестовым магазином.
6. **Боевые ключи** ЮKassa → очистка тестовых данных → первый трафик с UTM. После 20–50 оплат — подобрать
   таймаут LLM по p95 в `/admin`.

Желательно до закупки трафика, но не блокирует:
- шифрование email;
- Sentry;
- пометка внутреннего трафика;
- возвраты через вебхук;
- лимиты по IP;
- удаление данных по запросу.
