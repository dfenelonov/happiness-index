# Платный отчёт: генерация через LLM

## Вход в модель

Только агрегаты, без ПДн:

```json
{
  "happiness_index": 58,
  "vciom_answer": "скорее да",
  "traits": {"E": 2.5, "A": 4.0, "C": 3.5, "N": 3.5, "O": 4.5},
  "archetype": {"id": "quiet_explorer", "name": "Тихий исследователь"},
  "domains": {"sleep": 2.0, "relationships": 4.5, "work": 2.5, "money": 3.0, "meaning": 3.5},
  "leaks": ["sleep", "work", "money"]
}
```

## Выход: строгий JSON

```json
{
  "summary": "3–4 предложения: главное о человеке и его индексе",
  "archetype_deep_dive": "как черты проявляются в жизни, сильные стороны, слепые зоны",
  "leaks": [
    {"domain": "sleep", "why_for_you": "почему это бьёт именно по человеку с такими чертами",
     "actions": ["3–5 конкретных шагов, выполнимых за неделю"]}
  ],
  "strengths_to_use": ["3 сильные стороны и как опереться на них"],
  "plan_30_days": [{"week": 1, "focus": "...", "steps": ["..."]}],
  "remeasure_note": "предложение пройти тест снова через 30 дней"
}
```

Ответ валидируется по JSON-схеме (pydantic). Невалидный ответ → ретрай, после 3 неудач → fallback.

Реализация: промпт и запрещённые темы — `config/report_prompt.yaml`, параметры (модели, цены, ретраи,
дедлайн 55 с) — `config/app.yaml` → `report`, код — `app/services/reports.py`, провайдеры —
`app/services/llm.py`. Оценка на 20 профилях — `scripts/eval_reports.py`.

## Системный промпт (основа, правь осторожно)

> Ты — внимательный автор материалов о благополучии. Пиши по-русски, на «ты», тепло, конкретно и без
> пафоса. Опирайся только на переданные данные. Практики бери из доказательной психологии благополучия
> (сон, социальные связи, физическая активность, благодарность, осмысленные цели) и адаптируй под черты
> человека.
>
> Запрещено: ставить диагнозы и использовать клинические термины («депрессия», «тревожное расстройство»);
> обещать гарантированный результат; давать советы о лекарствах; упоминать политику, войну, экономику
> страны; упоминать MBTI и 16 типов Майерс-Бриггс; придумывать факты о человеке, которых нет во входных
> данных. Если низкий индекс — мягко добавь, что разговор со специалистом может помочь.
>
> Верни только JSON по схеме.

## Fallback

Шаблоны в `app/services/report_fallback/`: по одному тексту на архетип и на каждый домен утечки. Сборка
по тем же разделам. Отчёт помечается `status=fallback` и ставится в очередь на перегенерацию.

## Провайдеры

`LLM_PROVIDER=yandexgpt|gigachat`. Оба внутри РФ — это упрощает соответствие 152-ФЗ. Логировать
`tokens_in/out`, время ответа и стоимость; содержимое промпта в логи не писать.

Ориентир стоимости из финмодели: ≤ 15 ₽ на отчёт.
