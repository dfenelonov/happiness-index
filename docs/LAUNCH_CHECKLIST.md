# Чек-лист запуска: что нужно от владельца

Состояние на 30.10.2026. Код MVP готов (этапы 0–7, docs/PLAN.md); ниже — всё, что зависит от владельца.

**Легенда**

- 🔴 **Блокирует старт в production.** Приложение с `APP_ENV=production` не поднимается и пишет в лог
  `ConfigError` со списком проблем. Проверка — в коде, обойти её нельзя.
- 🟠 **Не блокирует старт, но нужно до открытия для людей** — юридически обязательно или без этого
  нельзя принимать деньги / верить метрикам. Код это не проверяет.
- 🟢 **Можно после запуска.**

Проверить, что осталось из 🔴, можно одной командой на сервере (без запуска сайта):

```bash
APP_ENV=production docker compose -f deploy/docker-compose.prod.yml run --rm --no-deps app python -c "import app.main"
```

Сейчас (без .env и правок конфигов) она выдаёт 36 проблем: 19 текстов шкал, юридические страницы, контакты помощи, ключи и
секреты, https и версия модели YandexGPT.

## 1. Ключи и секреты (`.env`, шаблон — `.env.example`, порядок — docs/DEPLOY.md)

| | Что | Комментарий |
|---|---|---|
| 🔴 | `SECRET_KEY`, `ADMIN_PASSWORD` | не пустые и не `change-me` |
| 🔴 | `EMAIL_ENCRYPTION_KEY` | валидный ключ Fernet; **после запуска не менять** — иначе email в заказах не расшифровать |
| 🔴 | `EMAIL_HASH_KEY` | отдельный ключ для поиска по email; после запуска не менять |
| 🔴 | `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` | тестовый ключ `test_…` — можно; боевой — см. раздел 7 |
| 🔴 | `LLM_PROVIDER` + ключи | `gigachat` → `GIGACHAT_AUTH_KEY`; `yandexgpt` → `YANDEXGPT_API_KEY` и `YANDEXGPT_FOLDER_ID`. Мок в production запрещён |
| 🔴 | `SMTP_HOST`, `MAIL_FROM` | письма со ссылкой на отчёт |
| 🔴 | `APP_BASE_URL=https://<домен>` | только https: secure cookie и ссылки в письмах |
| 🟠 | `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_PORT` | код не проверяет, но без них почта у большинства провайдеров не уйдёт |
| 🟠 | `GIGACHAT_CA_BUNDLE` | если сертификата НУЦ Минцифры нет в системе — GigaChat не ответит по TLS |
| 🟠 | `INTERNAL_LINK_TOKEN` | до закупки трафика: пометить браузеры команды, иначе их визиты попадут в метрики |
| 🟢 | `YANDEX_METRIKA_ID` | вспомогательная аналитика, метрики MVP считаются по серверным событиям |

Сохрани копии `EMAIL_ENCRYPTION_KEY` и `EMAIL_HASH_KEY` вне сервера (Lockbox / менеджер паролей).

## 2. LLM-отчёт

| | Что | Где |
|---|---|---|
| 🔴 | Закрепить версию YandexGPT Pro 5.1 вместо `latest` (если провайдер — YandexGPT) | `config/app.yaml` → `report.models.yandexgpt.version`. С `latest` / `rc` / `deprecated` production не стартует |
| 🟠 | Прогнать оценку на реальном провайдере и посмотреть `summary.md`: доля fallback, запрещённые темы, стоимость | `uv run python scripts/eval_reports.py --provider gigachat` (и `--model GigaChat` для сравнения с Lite) |
| 🟠 | Проверить один реальный отчёт глазами: тон, отсутствие диагнозов и обещаний | после тестовой оплаты |
| 🟢 | Сверять цены токенов и курс | `config/app.yaml` → `report.token_pricing` (справочные на 30.10.2026) |

Адаптеры YandexGPT и GigaChat проверены только на подставном HTTP — первый прогон с ключами покажет,
нужно ли поправить формат запроса.
