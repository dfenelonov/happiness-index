# Аналитика

Метрики MVP считаются по **серверной** таблице `events`. Яндекс Метрика — вспомогательная (вебвизор,
источники), она теряет часть данных из-за блокировщиков и отказа от cookie.

## События

Все события содержат `session_id` и `created_at`. В `props` — **никаких ПДн** и никаких ответов теста.

| Событие | Когда | props |
|---|---|---|
| `landing_view` | открыт лендинг | `utm_*`, `ref` (если есть) |
| `consent_given` | отмечено согласие | `version` |
| `test_start` | показан первый вопрос | — |
| `question_answered` | сохранён ответ | `index` (номер вопроса), `block` |
| `test_complete` | результат посчитан | `archetype_id` |
| `result_view` | открыта страница результата | `mode` (`owner` / `guest`) |
| `share_click` | клик по кнопке шеринга | `channel` (`vk` / `tg` / `copy` / `card`) |
| `paywall_view` | пейволл в зоне видимости | `price` |
| `checkout_start` | создан заказ | `price` |
| `payment_success` | вебхук `succeeded` | `price` |
| `payment_refund` | возврат | `price` |
| `report_view` | открыт отчёт | `status` (`ready` / `fallback`) |
| `sub_fakedoor_click` | клик «Хочу» на трекере | — |
| `sub_email_submit` | оставлен email | — |

## Дашборд `/admin`

Метрики считаются по уникальным сессиям; фильтр периода — по дате создания сессии (когорта).
Внутренние сессии (`sessions.is_internal`: dev-окружение, мок-оплаты, cookie `internal=1`) по умолчанию
исключены, переключатель «показать внутренние» их возвращает. Пороги — `config/app.yaml` → `metrics`.

Фильтры: период, `utm_source`, цена. Для каждой метрики — значение, 95% CI Уилсона, n, цвет:
зелёный — нижняя граница CI выше порога «идём дальше», красный — верхняя граница ниже порога «стоп»,
серый — данных недостаточно.

1. Воронка: `landing_view → test_start → test_complete → paywall_view → checkout_start → payment_success`
2. Дохождение по номеру вопроса — где бросают тест
3. Шеринг по каналам и вирусный коэффициент `test_start (с ref) / test_complete`
4. Конверсия и выручка на прошедшего по A/B-цене (что выгоднее: 490 × конверсия или 990 × конверсия)
5. Фейковая дверь: клики и email
