# CLAUDE.md — «Индекс счастья» (MVP)

## Что это за проект

Веб-сервис для российского рынка: короткий бесплатный тест (5–7 минут) показывает человеку личный
«индекс счастья», тип личности на основе Big Five и три главные «утечки счастья». Полный персональный
отчёт, сгенерированный LLM, продаётся за 690 ₽.

**MVP — это эксперимент, а не продукт.** Его единственная задача — измерить четыре метрики и сравнить
их с порогами (см. `docs/SPEC.md`, раздел 1):

| Метрика | Идём дальше | Стоп |
|---|---|---|
| Старт → прошёл тест | ≥ 60% | < 45% |
| Прошёл → поделился | ≥ 8% | < 4% |
| Прошёл → купил отчёт | ≥ 2,5% | < 1,2% |
| Купил → клик по фейковой подписке | ≥ 5% | — |

Любое решение, которое мешает точно измерить эти метрики, — неправильное решение.

## Где что лежит

- `docs/SPEC.md` — полное ТЗ: экраны, логика подсчёта, данные, API, критерии приёмки. **Читай первым.**
- `docs/PLAN.md` — этапы работ. Делай строго по порядку, один этап за раз.
- `docs/ANALYTICS.md` — события воронки и админ-дашборд.
- `docs/LLM_REPORT.md` — генерация платного отчёта: промпт, схема, ограничения.
- `docs/LEGAL.md` — юридические требования (152-ФЗ, оферта, согласия).
- `config/questionnaire.yaml` — вопросы, шкалы и правила подсчёта. Единственный источник правды по тесту.

## Стек (не менять без согласования)

- Python 3.12, FastAPI, SQLAlchemy 2 + Alembic, PostgreSQL (SQLite — только для локальной разработки и тестов)
- Server-side рендеринг: Jinja2 + HTMX, Tailwind (CDN допустим в MVP). Без SPA-фреймворков: нужен SEO.
- Pillow — генерация карточки результата 9:16 и OG-картинки
- `yookassa` — платежи (только тестовый режим, пока владелец явно не скажет иначе)
- LLM: YandexGPT или GigaChat через абстракцию `LLMProvider`; провайдер выбирается переменной окружения
- pytest, ruff; Docker + docker-compose

## Команды

```bash
docker compose up -d db           # Postgres
uv sync                           # зависимости (или pip install -e ".[dev]")
uv run alembic upgrade head       # миграции
uv run uvicorn app.main:app --reload
uv run pytest
uv run ruff check . && uv run ruff format .
```

Если какой-то команды ещё нет — создай её на соответствующем этапе `docs/PLAN.md` и обнови этот раздел.

## Правила работы

1. **Работай по этапам `docs/PLAN.md`.** В конце этапа: тесты зелёные, ruff чистый, коротко отчитайся,
   что сделано и как проверить. Не начинай следующий этап без подтверждения.
2. **Подсчёт результатов — только из `config/questionnaire.yaml`** и только в модуле `app/scoring/`.
   Модуль чистый (без БД и HTTP) и покрыт юнит-тестами на граничные значения.
3. **Не придумывай тексты вопросов стандартизированных шкал** (SWLS, BFI-10, PHQ-2, GAD-2). В конфиге стоят
   плейсхолдеры `TODO_LICENSED_TEXT`. Владелец вставит валидированные русские адаптации после проверки
   лицензий. Пока плейсхолдеры не заменены, в режиме `APP_ENV=production` приложение не стартует.
4. **Весь пользовательский текст — на русском**, на «ты», тёплый и спокойный тон. Без обещаний «вылечить»,
   «изменить жизнь за 7 дней», без медицинских терминов в результатах.
5. **Слово «MBTI» и названия 16 типов Майерс-Бриггс нигде не используем** — это чужая торговая марка.
   Типы — только свои архетипы из `config/questionnaire.yaml`.
6. **Скрининг (PHQ-2/GAD-2) — защитный контур, не продукт.** Человеку с флагом скрининга никогда не показывается
   пейволл, его результат никогда не используется в маркетинге. Сырые ответы скрининга не сохраняются в БД
   (см. `docs/LEGAL.md`).
7. **Персональные данные — минимум.** Тест анонимный. Email появляется только при покупке или подписке на
   уведомление. Никаких ПДн в URL, логах и аналитике. Ответы теста не отправляются в LLM вместе с email.
8. **Политика и новости — вне продукта.** Ни в интерфейсе, ни в отчёте нет рассуждений о причинах падения
   индекса в стране.
9. **Секреты — только в `.env`**, `.env` в `.gitignore`. Шаблон — `.env.example`.
10. **Каждое событие воронки пишется на сервер** (таблица `events`) в дополнение к Яндекс Метрике:
    метрики MVP считаются по серверным событиям, Метрика — вспомогательная.

## Чего не делать в MVP

Мобильное приложение, аккаунты с паролем, настоящая подписка с рекуррентными платежами, консультации,
блог/SEO-библиотека, мультиязычность, SPA. Если задача требует чего-то из этого — остановись и спроси.
